Crear un intercambio

Solo los administradores pueden crear intercambios. Todo intercambio nuevo comienza en estado pendiente.

Authorizations:
BearerAuth
Request Body schema: application/json
required
libro_id
required
integer >= 1
solicitante_id
required
integer >= 1
estado
string

Opcional; si se omite, se asigna pendiente.

Value: "pendiente"

Responses

http://localhost:8080/intercambios
